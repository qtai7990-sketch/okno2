# Бренд-графика

- `zhukovsky-airport-logo-source.png` — локальная копия знака Zhukovsky International Airport для внутреннего экрана агента первого этажа.
  - Источник: [официальный сайт аэропорта Жуковский](https://zia.aero/en/).
  - Получено 31.10.2026 для реализации задачи владельца проекта.
  - Не использовать за пределами данного интерфейса без проверки правил использования бренда.

Для «Документ-экспресс» в открытых источниках не найден подтверждённый утверждённый знак. В UI используется нейтральный текстовый знак продукта; если у команды есть брендбук/вектор, замените блок `.express-brand` в `web/app.js`.
