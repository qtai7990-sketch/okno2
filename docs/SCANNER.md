# Подключение сканера документов Smart Engines

Рабочая сборка (`prod`) пока сообщает «сканер не подключён». Порядок подключения после покупки лицензии:

1. Получить у Smart Engines SDK для Android: Smart ID Engine с чтением NFC-чипа (eMRTD), распознаванием паспортов СНГ и миграционной карты РФ, штрихкодов (IMEI). Уточнить поддержку паспортов Таджикистана.
2. Положить файлы SDK (`.aar` и файлы лицензии/конфигурации) в `android/app/libs/` — **не в открытый доступ**, репозиторий должен быть закрытым; ключ лицензии — в секреты GitHub, не в код.
3. Прислать мне документацию SDK — я допишу `SmartEnginesScanner.kt` по интерфейсу `DocumentScanner`:
   - `passport` → поля `surname, given, cyr, country, country_name, number, dob, sex, expiry, has_ru_text, source ("chip"|"mrz"), checks[]`;
   - `migcard` → `series, number, entry_date, kpp, purpose, stay_until`;
   - `imei` → `imei` (15 цифр);
   - `ruid` → подтверждение QR RuID.
4. Данные распознавания обрабатываются на планшете; на сервер уходят только структурированные поля. Изображения документов не сохраняются.

`has_ru_text` определяется по справочнику «страна + серия паспорта» — справочник нужно проверить по образцам паспортов.
